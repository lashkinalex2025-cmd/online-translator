Создай современное PWA и Android-приложение под названием «Онлайн Переводчик».

Приложение должно быть функционально похоже на Яндекс Переводчик, с удобным, быстрым и интуитивно понятным интерфейсом.

Основной функционал:
Перевод текста между следующими языками:

русский
английский
немецкий
французский
испанский
Пользователь должен иметь возможность:

выбирать исходный язык
выбирать язык перевода
вводить текст вручную
менять языки местами одной кнопкой
видеть результат перевода мгновенно
копировать переведенный текст
очищать поля ввода
прослушивать исходный и переведенный текст через TTS
Голосовой перевод в реальном времени:

приложение должно запрашивать доступ к микрофону
после нажатия кнопки «Старт» приложение начинает слушать речь пользователя
распознает речь в реальном времени
автоматически переводит распознанный текст на выбранный язык
показывает как исходный текст, так и перевод
процесс продолжается непрерывно, пока пользователь сам не нажмет кнопку «Стоп»
во время работы должен быть индикатор записи/прослушивания
если микрофон недоступен или доступ запрещен, показать понятное сообщение об ошибке
История переводов:

сохранять последние переводы локально
отображать список истории
возможность повторно открыть прошлый перевод
возможность удалить отдельные записи или очистить всю историю
Избранное:

пользователь может добавлять переводы в избранное
отдельный экран/раздел для избранных переводов
Требования к интерфейсу:
современный минималистичный дизайн
стиль, похожий на крупные переводчики: чистый UI, большие кнопки, удобные переключатели языков
адаптивная верстка для смартфонов, планшетов и десктопа
поддержка светлой и темной темы
интерфейс на русском языке
плавные анимации и приятный UX
большие кнопки Старт и Стоп для голосового перевода
Требования к PWA:
приложение должно быть устанавливаемым как PWA
добавить manifest.json
добавить service worker
обеспечить офлайн-работу интерфейса и кэширование статических ресурсов
корректные иконки приложения
splash screen
адаптация под мобильные устройства
Требования к Android:
подготовить проект так, чтобы его можно было собрать как Android-приложение
можно использовать Capacitor или Cordova для упаковки PWA в Android
доступ к микрофону должен корректно работать на Android
приложение должно запрашивать необходимые разрешения
Технические требования:
Использовать современный стек, например:
React / Next.js или Vue
для UI — современный компонентный подход
для хранения истории и избранного — localStorage / IndexedDB
Для голосового ввода использовать:
Web Speech API или аналогичный механизм распознавания речи
Для перевода предусмотреть подключение к API переводчика
Архитектура должна быть чистой и масштабируемой
Код должен быть структурированным, понятным и готовым к дальнейшему расширению
Дополнительно:
предусмотреть экран загрузки
добавить красивую иконку приложения
показать состояние: «Слушаю...», «Перевожу...», «Остановлено»
предусмотреть защиту от пустого ввода
если выбраны одинаковые языки, корректно обрабатывать это
добавить кнопку обмена текстом
сделать акцент на высокой скорости работы и простоте использования
Что нужно на выходе:
Полный исходный код приложения
PWA-структура с manifest и service worker
Android-совместимая упаковка
Красивый современный UI
Готовность к запуску и дальнейшей доработке.
